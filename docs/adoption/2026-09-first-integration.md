## 给试用者的说明

目标是把你已有的三个 Spring AI 方法接入 SDK：一个查询、一个业务预览、一个需要审批的写操作。
先保存原始签名，保留 DTO、集合和代理形式；如果它们不受支持，就记录阻塞，不要先改成示例形状。
使用本地测试数据和替身执行写操作，不接生产接口。

1. 记录 Java、Spring AI、Spring Boot、操作系统以及 SDK 的版本/提交。
2. 按 [独立消费示例](../../examples/spring-ai-adoption/README.md) 用全新公共缓存从 Maven Central 消费公开 0.5.0；无需先安装 SDK 源码。需要 CGLIB 修复时改走[未发布候选步骤](2026-10-proxy-reproduction.md)，单独记录源码提交、源码 ZIP 的可信 SHA256 映射及候选缓存路径，并在自己工程构建时继续显式使用该缓存。两种来源不能混记。
3. 用你的三个方法替换示例工具，显式配置应用授权、审批、幂等、审计和可信上下文。
4. 验证无审批不写入、精确审批后只执行一次、同 key 重试不重复、改变参数和租户被拒绝。
5. 记录卡住的位置、错误码、查阅的文档，以及每一次维护者提示。遇到不支持签名时保留最小复现。

试用者应未参与 SDK 实现。若由项目维护者在另一工程试用，应标为维护者接入，不能当作独立验证。
建议体验目标：首次成功调用 30 分钟，三个方法接入 2 小时；这是待测目标，下载等待单列。
